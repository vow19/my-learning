#### WinSCP畫面，左邊是你的筆電，右邊是遠端伺服器，傳檔案用winscp、terminal介面用putty    
把程式碼與資料集丟上去（WinSCP）：  
在自己的電腦寫好Python程式碼、整理好訓練資料集後，直接用滑鼠從左邊拖曳到右邊的資料夾。  

借伺服器的算力跑實驗（PuTTY）：  
回到黑底白字的 PuTTY 視窗下指令（例如 python train.py）。  

把跑好的成果載回來看（WinSCP）：  
模型訓練完產生出來的權重檔（.pt、.pth）、圖表（Accuracy/Loss 曲線圖）或預測結果 CSV，再從右邊拖曳回左邊本機查看。
